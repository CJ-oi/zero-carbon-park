使用说明

网站围绕“数据够不够、现状是什么、差距在哪里、怎么减、花多少钱”展开。公开资料先用于发现问题和补充线索；正式核算只使用同一边界、同一年度、可追溯的园区数据。

园区现场

地图点位用于园区导航，不代表法定四至。点击点位可查看产业结构、建设周期、公开事实、来源和限制说明。

数据够不够

勾选已取得材料，生成带责任部门、最低材料和建议时限的补数任务，并可导出 CSV。

现状是什么

选择园区，从管委会、企业、能源运营、公共设施、监管评估和研究评估视角查看资料画像。结构相似园区只用于确定调研对象，不是绩效排名。

差距在哪里

确认边界和自然年后，录入能源和排放数据。系统计算单位能耗碳排放及引导指标差距；数据门槛未通过时不输出达标结论。

怎么减

措施分为无悔型、条件型和战略型。计量、设备效率、蒸汽、余热、水循环和工业协同优先作为无悔工作。绿电直连、储能和微电网需先核对源荷、网架、计量、结算和责任边界。

花多少钱

录入投资、年度减排、年度收益、运维、寿命和参数证据后，系统形成预算约束下的项目组合、年度路径和 Markdown 可行性初筛报告。

自动更新与报告

公开仓库中的定时工作流每 6 小时检查来源，更新滚动档案、日报、周报和示范可行性报告。定时更新是周期性检查，不是秒级数据流。

数据更正

点击网站底部“提交数据更正”进入 GitHub Issues。请提供园区对象、原文入口、发布日期、建议修改内容和核验理由。不要上传企业敏感台账、合同价格或个人信息。

使用边界

网站用于前期筛查和项目排序，不替代碳核查、节能审查、环评、电网接入审查、工程可研和投资决策。
